폰 바탕화면에 아이콘을 만들어 두면, 누를 때마다 바로 열립니다.

✅ 이미 설치되어 있습니다

이 화면은 아이콘으로 열렸습니다. 아래 버튼으로 포털을 여세요.

포털 열기

⚠ 카카오톡 화면에서는 설치가 안 됩니다

아래 버튼을 누르면 크롬으로 이 화면이 다시 열립니다. 거기서 설치하세요.

버튼을 눌러도 안 넘어가면: 화면 오른쪽 아래(또는 위) ⋮ 나 ⋯ → 다른 브라우저로 열기를 누르세요.

안드로이드 (삼성 갤럭시 등)

위 버튼을 누르고, 나오는 창에서 설치를 한 번 더 누르면 끝입니다.

버튼이 안 보이면 이렇게 하세요

  1. 크롬에서 이 화면이 열려 있는지 확인합니다. (카카오톡에서 열었다면 위의 크롬으로 열기부터)
  2. 화면 오른쪽 위 ⋮ (점 세 개)를 누릅니다.
  3. 목록에서 앱 설치 또는 홈 화면에 추가 를 누릅니다.
  4. 그다음 나오는 창에서 설치 를 누릅니다.
「설치」와 「바로가기 만들기」가 둘 다 보이면 → 꼭 「설치」를 누르세요.
· 설치: 앱처럼 깔려서, 아이콘을 누르면 포털이 꽉 찬 화면으로 바로 열립니다. (추천)
· 바로가기 만들기: 크롬 안에서 주소창이 보이는 채로 열립니다. 이미 눌렀어도 써도 됩니다.
삼성 인터넷을 쓰신다면: 아래쪽 ≡ → 현재 페이지 추가 → 홈 화면. 주소창 옆에 ↓ 설치 아이콘이 보이면 그걸 눌러도 됩니다.
설치가 끝나면 폰 바탕화면이나 앱 목록에 한보금on 활동지원 아이콘이 생깁니다. 바로 안 보이면 바탕화면을 옆으로 넘겨 보세요.

아이폰

  1. 사파리에서 이 화면이 열려 있는지 확인합니다. (카카오톡에서 열었다면 위의 사파리로 열기부터)
  2. 화면 아래 가운데 공유 버튼 □↑ 을 누릅니다. (아래쪽 막대가 안 보이면 화면을 살짝 위로 밀어 보세요)
  3. 나온 목록을 위로 조금 밀어 홈 화면에 추가 를 누릅니다.
  4. 오른쪽 위 추가 를 누르면 끝입니다.
아이폰은 애플 규칙상 버튼 하나로 설치할 수 없어서 위 순서로 직접 추가해야 합니다. 목록에 홈 화면에 추가가 없으면 맨 아래 동작 편집에서 켤 수 있습니다.
끝나면 폰 바탕화면에 한보금on 아이콘이 생깁니다.

PC (윈도우)

  1. 아래 버튼으로 설치 파일을 받습니다.
  2. 받은 파일을 오른쪽 클릭 → 모두 압축 풀기.
  3. 풀린 폴더의 install-icon.bat을 더블클릭합니다. 파란 경고창이 뜨면 추가 정보 → 실행.
PC 아이콘 설치 파일 받기
크롬·엣지를 쓰시면 주소창 오른쪽의 설치 아이콘(⊕ 또는 화면에 ↓)을 눌러도 됩니다.

아이콘을 누르면 포털 로그인 화면이 나옵니다.
