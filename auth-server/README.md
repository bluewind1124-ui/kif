# 계정 서버 만들기 (클라우드플레어 무료)

한보금on 활동지원의 **로그인 · 계정 신청 · 승인 · 비밀번호 변경 · 비밀번호 찾기**를 맡는 작은 서버입니다.

- 이 서버에 있는 것: **아이디, 비밀번호(되돌릴 수 없는 형태), 권한(FC/관리자), 상태(승인 대기/사용/정지)** 만
- 이 서버에 없는 것: 이름·소속·고객 자료 (고객 자료는 각자의 기기와 개인 클라우드에 보관)
- 비용: 무료 (FC 수백 명이 매일 써도 무료 범위 안)
- 걸리는 시간: 처음 한 번, 약 15분

---

## 1단계. 클라우드플레어 무료 가입 (3분)

1. 컴퓨터에서 **https://dash.cloudflare.com/sign-up** 을 엽니다.
2. **이메일**과 **비밀번호**를 넣고 **Sign up**(가입)을 누릅니다.
   - 사람 확인 체크 상자가 나오면 직접 눌러 주세요.
3. 넣은 이메일로 확인 메일이 옵니다. 메일 안의 **Verify email**(이메일 확인) 버튼을 누릅니다.
4. 가입이 끝나면 클라우드플레어 첫 화면(대시보드)이 열립니다.
   - "도메인(웹사이트)을 추가하라"는 화면이 나와도 **건너뛰세요.** 도메인은 필요 없습니다.
   - 신용카드는 넣지 않아도 됩니다. 무료 플랜으로 충분합니다.

> 화면이 영어로 나오면 오른쪽 위 사람 모양 → **Language** → **한국어**로 바꿀 수 있습니다. 아래 안내에는 영어 이름을 괄호로 함께 적었습니다.

## 2단계. 서버(Worker) 만들기 (5분)

1. 왼쪽 메뉴에서 **Workers 및 Pages (Workers & Pages)** 를 누릅니다.
2. **생성 (Create)** → **Worker 생성 (Create Worker)** 을 누릅니다.
   - 템플릿을 고르라고 하면 **Hello World** 를 고릅니다.
   - 처음이면 내 주소 이름(**workers.dev 하위 도메인**)을 정하라고 나옵니다. 영문으로 아무거나 정하세요 (예: `hanbogeum`).
3. 이름 칸에 **`kif-auth`** 를 적고 **배포 (Deploy)** 를 누릅니다.
4. 배포가 끝나면 **코드 편집 (Edit code)** 을 누릅니다.
5. 왼쪽 코드 창의 내용을 **모두 지우고**(Ctrl+A → Delete), 이 폴더의 **`worker.js` 파일 내용 전체**를 복사해 붙여넣습니다.
   - 바탕화면 `한보금 신채널 교육지원\mirae-bohum\auth-server\worker.js` 를 메모장으로 열어 Ctrl+A → Ctrl+C
6. 오른쪽 위 **배포 (Deploy)** 를 누릅니다.

## 3단계. 계정 저장 공간(KV) 만들고 연결하기 (3분)

1. 왼쪽 메뉴에서 **스토리지 및 데이터베이스 (Storage & Databases)** → **KV** 를 누릅니다.
2. **생성 (Create)** 을 누르고 이름에 **`kif-accounts`** 를 적은 뒤 **추가 (Add)** 를 누릅니다.
3. 다시 **Workers 및 Pages** → **kif-auth** → 위쪽 **설정 (Settings)** 탭으로 갑니다.
4. **바인딩 (Bindings)** → **추가 (Add)** → **KV 네임스페이스 (KV namespace)** 를 고릅니다.
   - 변수 이름(Variable name): **`ACCOUNTS`** (대문자 그대로)
   - KV 네임스페이스: **kif-accounts**
   - **배포 (Deploy)** 또는 **저장 (Save)** 을 누릅니다.

## 4단계. 비밀값 2개 넣기 (2분)

같은 **설정 (Settings)** 화면의 **변수 및 비밀 (Variables and Secrets)** → **추가 (Add)**

| 종류 (Type) | 이름 (Variable name) | 값 (Value) |
|---|---|---|
| **비밀 (Secret)** | `SECRET` | 아무 글자 **40자 이상**. 키보드로 영문·숫자를 막 쳐서 만드세요. 남에게 알려 주지 말고 어디에도 적어 두지 않아도 됩니다. |
| **텍스트 (Text)** | `ADMIN_ID` | 사장님(관리자)이 쓸 **아이디**. 영문 소문자·숫자 (예: 회사 사번 `k0001`) |

넣은 뒤 **배포 (Deploy)** 를 누릅니다.

## 5단계. 잘 되는지 확인 (1분)

1. **kif-auth** 화면 위쪽에 있는 주소(`https://kif-auth.○○○.workers.dev`)를 눌러 엽니다.
2. 아래처럼 `"ready":true` 가 보이면 성공입니다.
   ```
   {"ok":true,"service":"한보금on 활동지원 계정 서버","ready":true,"missing":[]}
   ```
   - `"ready":false` 이면 `missing` 에 빠진 항목이 적혀 있습니다. 그 단계를 다시 확인하세요.
3. 이 주소를 복사해 둡니다.

## 6단계. 포털에 연결 (2분)

1. 포털(https://bluewind1124-ui.github.io/kif/)에 **체험용 관리자 계정**(admin / admin)으로 로그인합니다.
2. **관리자 페이지 → FC 계정 관리** 칸에 5단계의 주소를 붙여넣고 **계정 서버 연결** 을 누릅니다. (GitHub 토큰이 필요합니다)
3. 1~2분 뒤 **로그아웃** 합니다. 로그인 화면에 **「처음이신가요? 계정 신청」** 이 보이면 연결된 것입니다. 이때부터 체험용 계정은 막힙니다.
4. **계정 신청** 을 누르고 4단계의 **ADMIN_ID** 로 아이디를, 원하는 비밀번호를 넣어 신청합니다. → 바로 **관리자** 계정이 됩니다.
5. 그 아이디·비밀번호로 로그인하면 **관리자 페이지 → FC 계정 관리** 에서 신청 승인, 비밀번호 초기화 요청 처리, 정지·삭제를 할 수 있습니다.

---

## 운영 방법

- **FC가 계정 신청** → 관리자 화면 「승인 대기」에서 **승인** (회사 아이디·사번으로 본인인지 확인)
- **FC가 비밀번호를 잊음** → 로그인 화면 「비밀번호를 잊으셨나요?」에서 요청 → 관리자 화면 「비밀번호 초기화 요청」에서 **임시 비밀번호 발급** → 안내 문구를 복사해 카톡으로 전달 → FC가 임시 비밀번호로 로그인하면 「내 정보」에서 새 비밀번호로 바꾸라는 안내가 나옴
- **FC가 비밀번호를 바꾸고 싶음** → 로그인 후 위쪽 **내 정보** → 비밀번호 변경 (지금 비밀번호를 알아야 바꿀 수 있어 승인 없이 바로)
- **퇴사·휴직** → 「정지」 또는 「삭제」
- 비밀번호를 10번 틀리면 그 계정은 10분 동안 잠깁니다.
- 로그인은 12시간 동안 유지됩니다. 그 뒤에는 다시 로그인합니다.

## 알아 두실 점

- 관리자 비밀번호를 잊으면: 다른 관리자 계정이 있으면 그 계정으로 초기화합니다. 관리자가 한 명뿐이면 클라우드플레어 **KV → kif-accounts** 에서 내 아이디 줄을 지우고 다시 신청하면 됩니다. 그래서 **관리자 계정을 2개** 만들어 두는 것을 권장합니다.
- 비밀번호는 서버에 원래 글자로 저장되지 않습니다. 관리자도 FC의 비밀번호를 볼 수 없고, 초기화만 할 수 있습니다.
- 서버 코드를 고치면 2단계 5~6번처럼 다시 붙여넣고 배포합니다. 계정 목록(KV)은 그대로 남습니다.
