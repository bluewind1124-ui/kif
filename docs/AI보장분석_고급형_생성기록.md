## 주요 결정과 이유

- **AI 없이 동작하는 규칙 기반 문장**: 결과가 항상 같고 비용이 없음. AI는 설계서 판독에만 사용.
- **세법은 '알림 + 사람 확인 후 적용'**: 조문을 잘못 읽어 고객 자료 숫자가 틀리는 위험을 막기 위해 자동 반영하지 않음.
- **판례 미포함**: 사건번호를 검증할 수 없어 넣지 않음. 검증 목록이 생기면 같은 방식으로 추가 가능.
- **저장 위치**: 모든 데이터는 브라우저(localStorage)에 저장. 포탈 이식 시 `load()`/`save()` 두 함수만 서버 API로 바꾸면 됨.

## 알려진 한계 / 확인 필요

- 2026년 세법 기준표는 2025년 값을 옮겨 둔 상태 → 첫 점검 후 확인 체크 필요
- 금융소득 종합과세 계산은 배당 가산(Gross-up)·배당세액공제 미반영
- 연금상품 계산은 사업비·해지공제·운용보수를 단순화한 추정 → 설계서 예시 연금액·환급률을 넣으면 그 값을 우선 사용
- 종신연금은 생명표 대신 100세까지 균등 지급으로 추정, 총 수령액은 기대수명 기준
- 투자성향별 권고 배분, 담보별 권장 금액, 주택연금 월수령액은 예시 기준 → 회사 기준으로 교체
- 외부 호출 기능(법령 점검, AI 판독)은 claude.ai 미리보기 안에서는 막힘 → 파일을 직접 열거나 포탈에서 사용
