# 법령·세법 업데이트 설명서

보장분석 플래너(`coverage-analyzer.html`)의 세법 수치와 법령 연결을 최신으로 유지하는 방법입니다.
작성일: 2026-10-20

---

## 1. 무엇이 법령·세법에 따라 바뀌나

| 구분 | 어디에 쓰이나 | 어떻게 바뀌나 |
|---|---|---|
| **세법 기준표 (연도별)** | 연금·자산 계산, 제안서 문구, 발표 노트의 숫자 | 「기준 설정 → 세법 기준표」에서 연도별로 관리. **법령·세법 점검**으로 법령 원문 숫자와 비교해 골라서 적용 |
| **조건별 법령 연결** | 제안서 「근거자료」와 각 섹션의 법령 링크 | 입력값이 조건에 맞을 때만 연결. 링크는 국가법령정보센터 **현행 조문**으로 열림 |
| **발표 노트·판단 문장** | 제안서 각 섹션 | 계산값에 따라 자동으로 바뀜. 법 설명 문장 자체는 프로그램에 고정 (제도가 바뀌면 프로그램 수정 필요) |

## 2. 준비 (처음 한 번)

1. **법제처 Open API 인증키(OC) 신청**
   - 국가법령정보 공동활용 <https://open.law.go.kr> 회원가입 → Open API 사용 신청
   - 승인되면 받는 **OC 값**(보통 이메일 아이디)을 메모합니다.
2. **실행 위치 확인**
   - claude.ai 미리보기 링크 안에서는 보안 정책 때문에 외부 조회가 막힙니다.
   - `coverage-analyzer.html` 파일을 크롬·엣지에서 **직접 열거나**, 포탈에 올린 화면에서 점검합니다.
3. 「법령·세법 점검」 창에 OC 값을 한 번 입력하면 브라우저에 저장됩니다.

## 3. 평소 사용 순서 (제안서 만들기 전)

1. 「상담 설계」 화면 위쪽(또는 제안서 화면 도구 모음)의 **법령·세법 점검** 아이콘 상태를 봅니다.

   | 표시 | 뜻 | 할 일 |
   |---|---|---|
   | 🟢 최신 | 30일 안에 점검, 변경 없음 | 그대로 제안서 작성 |
   | 🟡 점검 필요 | 점검한 적 없음 / 30일 경과 / 계산 연도 바뀜 | 점검 실행 |
   | 🔴 변경 발견 | 개정 있음 또는 기준표와 다른 값 | 확인 후 적용 |

2. 아이콘을 눌러 **지금 점검**을 누릅니다. (약 5초)
3. **① 법령 개정 확인**: 감시 법령 8개의 공포일·시행일을 지난 점검과 비교합니다.
   - 「개정됨」이 나오면 법령 이름을 눌러 원문을 확인합니다.
   - 계산과 관계없는 조문 개정일 수도 있습니다. 확인 후 **법령 개정 확인 완료로 기록**을 누르면 다음 점검부터 이 날짜 기준으로 비교합니다.
4. **② 세법 기준표와 법령 원문 비교**: 항목별로 「일치 / 다름 / 자동 판독 불가」가 나옵니다.
   - 「시행 예정 개정 있음」 표시가 있으면 그 날짜부터 바뀌는 조문이 있다는 뜻입니다. 시행일 이후 다시 점검하세요.
5. **다른 값 적용**: 「다름」 항목만 체크된 채로 나옵니다.
   - 적용할 **연도**를 고르고 **선택한 값 적용**을 누릅니다.
   - 그 연도 표가 없으면 직전 연도를 복사해 만든 뒤 고른 값만 바꿉니다.
   - 적용 후 그 연도로 계산이 바뀌고, 기준 설명에 「○월 ○일 법령 원문 점검 반영」이 기록됩니다.
6. **③ 직접 확인할 항목**(시행령·고시)은 원문 링크를 열어 「기준 설정 → 세법 기준표」에서 직접 고칩니다.

## 4. 해가 바뀔 때 (연말·연초)

1. 12월: 다음 해 세법 개정안이 공포되면 「기준 설정 → 세법 기준표 → **다음 연도 추가**」.
2. 바뀐 칸만 고칩니다. 기본값과 다른 칸은 굵게 표시됩니다.
3. 1월 1일 이후 **법령·세법 점검**을 실행해 원문과 일치하는지 확인합니다.
4. 「개정 내용을 확인했음」에 체크하면 제안서 표지의 '확인 필요' 표시가 사라집니다.
5. 계산 연도: 「이 연도로 계산」을 누르지 않았다면, 표에 있는 연도 중 오늘 이전의 가장 최근 연도를 자동으로 씁니다. 직접 고른 적이 있으면 그 연도에 고정되니, 새해에는 다시 골라 주세요.

## 5. 자동 판독이 안 될 때

- 개정으로 조문 문장 구조가 바뀌면 「자동 판독 불가」가 나옵니다.
- 원문 링크를 열어 숫자를 확인하고 세법 기준표에서 직접 고치세요.
- 자주 반복되면 프로그램의 `TAX_CHECKS` 정규식(조문에서 숫자를 찾는 규칙)을 고쳐야 합니다. 이 설명서와 함께 Claude에게 요청하면 됩니다.

## 6. 법령 연결 규칙 바꾸기

- 연결 조건은 프로그램의 `lawsFor()` 함수, 조문 목록은 `LAW_LIB`에 있습니다.
- 조문 번호가 바뀌거나(예: 조문 이동), 새 제도를 연결하려면 이 두 곳을 고칩니다.
- 판례는 사건번호를 검증한 목록이 있을 때만 같은 방식으로 추가합니다.

## 7. 한계와 주의

- 이 기능은 **알림 + 사람 확인 후 적용** 방식입니다. 세율을 자동으로 바꾸지 않습니다.
- 공포됐지만 시행 전인 개정은 「시행 예정」 표시만 하고, 비교는 현행 조문 기준입니다.
- 계산은 상담용 추정이며, 실제 세액은 개인 소득 구성·공제에 따라 다릅니다. 금융소득 종합과세 계산은 배당 가산(Gross-up)·배당세액공제를 반영하지 않습니다.
- 데이터(기준표·점검 기록·인증키)는 그 브라우저에만 저장됩니다. 다른 PC로 옮길 때는 「기준 설정 → 데이터 백업」을 쓰세요.
