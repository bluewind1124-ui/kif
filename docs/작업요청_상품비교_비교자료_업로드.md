# 작업 요청 — 관리자 「상품 비교」 비교자료 업로드 화면 + 자료 관리 연동

- 요청일: 2026-10-23 (조진열)
- 상태: **대기** (다음 작업 세션에서 시작)
- 대상 파일: `index.html` (관리자 › 자료 관리 · 상품 비교), 필요하면 `classic/*.html`, `content.json`

## 배경

관리자 페이지 「상품 비교」에는 **이번 달의 원픽** 입력 화면(가이드 PDF 올리기 → AI로 읽기 → 비교표 갱신)만 있다.
나머지 비교 도구 5종은 매달 자료가 바뀌는데, 새 자료를 올리는 화면이 없다.

| id | 메뉴 이름 | 화면 파일 |
|---|---|---|
| `life` | 생명보험 가이드북 비교 | `classic/life.html` |
| `nonlife` | 담보별 비교견적 | `classic/nonlife.html` |
| `wholelife` | 단기납 종신보험 비교 | `classic/wholelife.html` |
| `critical3` | 3대질병진단비 비교 | `classic/critical3.html` |
| `ceoterm` | 경영인 정기보험 비교 | `classic/ceoterm.html` |

(목록 기준: `index.html`의 `CMP_BASE`, 메뉴 정의 `['상품 비교',[…]]`)

## 해야 할 일

1. **관리자 › 상품 비교 아래에 「비교자료 업로드」 화면 추가**
   - 위 5개 항목을 한 화면에 카드(또는 표)로 나열한다.
   - 항목마다: 파일 올리기(PDF·엑셀·PPT·그림) · 기준월(연.월) · 마지막 올린 날짜 표시 · 열어보기 · 지우기.
   - 「이번 달의 원픽」 입력 화면과 같은 묶음(상품 비교)에 둔다.
2. **업데이트하면 이전 자료는 보관하지 않는다**
   - 새 파일을 올리면 이전 파일은 저장소에서 지우고 교체한다(원픽의 `onepicks` 같은 지난 자료 보관 없음).
   - `content.json`에도 항목별로 최신 1건만 남긴다.
3. **자료 관리와 연동**
   - 관리자 › 자료 관리 「상품 비교」 탭(`CM_TABS`의 `compare`)에서 같은 자료가 보이고, 거기서 교체·지우기를 해도 비교자료 업로드 화면에 그대로 반영된다(반대도 같음).
   - 파일을 두 군데 따로 저장하지 않는다. 한 곳(`content.json`의 항목 + 파일 1개)을 함께 본다.
   - 커밋 방식은 기존 「모든 FC에게 올리기」(GitHub API, main 한 번에 커밋)를 그대로 쓴다.
4. **FC 화면 반영**
   - FC가 상품 비교 › 각 도구를 열었을 때 그 달 비교자료(원본 파일)를 열어볼 수 있게 한다(예: 도구 화면 위쪽 「이번 달 원본 자료 · 기준월」 버튼).
5. **건드리지 않을 것**
   - 「이번 달의 원픽」 입력·AI 읽기·지난 원픽 보관 기능은 지금 그대로 둔다.
   - 한국보험금융 톤앤매너(남색 #0F2340 · 금색 #CD9B34)와 기존 관리자 화면 모양을 따른다.

## 확인할 것 (작업 전에 사용자에게)

- 비교 도구 5종의 표 데이터를 올린 파일(엑셀 등)로 **자동 갱신**까지 해야 하는지, 아니면 원본 파일을 **올려두고 열람**만 하면 되는지.
  (원픽처럼 AI로 읽어 표를 다시 그리는 방식은 범위가 크므로 먼저 묻는다.)
